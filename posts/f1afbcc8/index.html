理论

什么是强化学习

  • 状态：一个向量，描述当前智能体的状态；
  • 动作：描述智能体做出的决策；
  • 策略：状态的函数，输出一个动作，满足；
  • 奖励reward：处于状态使用动作a后会达到一个新状态，输出一个对应的float奖励值；
  • 回报return：一组状态序列对应了一组奖励序列，将奖励序列的折扣加权和定义为状态序列的回报；
  • 状态-动作-值函数：状态和动作的函数。定义为处于状态时采取动作，随后到达状态，在状态下采取最优行动的期望return。这其实是bellman方程的定义。方程中的表示对状态取期望，因为在状态下取动作a到达的下一个状态往往不是确定的：

一句话描述什么是强化学习：学习一个策略，使得当我处于状态采取动作满足满足。

所以强化学习的核心实际上是把状态-动作-值函数搞出来，也就是求解bellman方程。有了就得到了！

那如何求解bellman方程呢？列举一部分求解方法及其适用场景：

  • 已知，可直接用bellman方程计算
    • 动态规划递推：状态转移图没有环，直接顺推、逆推求解就行，参考背包问题的动态规划解法。得到的状态-动作值函数Q是精确的
    • Q值迭代方法：状态转移图有环。当时Bellman算子是压缩映射，得到的状态-动作值函数Q是精确的
  • 不知道（在真实环境，而非模拟环境中，不知道概率是很常见的），从而只能先随机猜测一个然后通过在环境中采样的方式去逼近真实的Q
    • Q-learning办法：状态空间和动作空间比较小的情况，满足条件有收敛到真实Q的保证
    • Deep Q Network(DQN)：状态和动作空间很大。用神经网络近似状态-动作值函数Q，没有收敛到真实Q的保证

技术实现

Q值迭代方法

已知状态空间[0,1,2,3,4,5]，动作空间[0,1]，各个状态下的奖励[100,0,0,0,0,40]，,，计算Q。

Q值迭代方法
import copy
import random

sspace = [0,1,2,3,4,5]
aspace = [0,1]
reward = [100,0,0,0,0,40]
Q = [[0 for a in aspace] for s in sspace]  # 猜测Q
gamma = 0.9

delta = float('inf')
while True:
    if delta<1e-12:
        break # 收敛判断
    Q_copy = copy.deepcopy(Q)
    for s in sspace[1:-1]:
        for a in aspace:
            if a == 0:
                Q_copy[s][a] = 0.8*(reward[s-1]+gamma*max([Q_copy[s-1][aprime] for aprime in aspace]))\
                +0.2*(reward[s+1]+gamma*max([Q_copy[s+1][aprime] for aprime in aspace]))
            else:
                Q_copy[s][a] = 0.8*(reward[s+1]+gamma*max([Q_copy[s+1][aprime] for aprime in aspace]))\
                +0.2*(reward[s-1]+gamma*max([Q_copy[s-1][aprime] for aprime in aspace]))
    delta = max([abs(Q[s][a]-Q_copy[s][a]) for s in sspace for a in aspace]) # 当Q = Q_copy差别不大，就收敛到真实Q了
    Q = Q_copy

print('得到状态-动作——值函数')
print(Q)

Q-learning方法

已知状态空间[0,1,2,3,4,5]，动作空间[0,1]，各个状态下的奖励[100,0,0,0,0,40]，,，假设环境是个黑箱（agengt本身不知道），计算Q。

相关包导入
import gymnasium as gym
from gymnasium import spaces
import numpy as np
利用gymnasium自定义这样一个黑箱环境，用于采样
class BlackBoxEnv(gym.Env):
    def __init__(self):
        super().__init__()
        # 必须：状态空间和动作空间
        self.observation_space = spaces.Discrete(6)  # 状态 0~5
        self.action_space = spaces.Discrete(2)       # 动作 0=左，1=右
        # 奖励表：到达状态 0 得 100，到达状态 5 得 40
        self.rewards = [100, 0, 0, 0, 0, 40]
        self.state = 1

    def reset(self, seed=None, options=None):
        """
        随机初始化智能体的状态
        """
        super().reset(seed=seed)
        self.state = int(self.np_random.choice([1, 2, 3, 4]))
        return self.state, {}

    def step(self, action):
        """
        做一个动作，返回：下一个状态、即时奖励，下一个状态是否是边界状态、当前回合步数是否达到上限
        """
        
        # 黑箱转移：80% 按动作走，20% 反向
        if self.np_random.random() < 0.2:
            action = 1 - action  # 反向
    
        if action == 0:
            self.state = max(0, self.state - 1)  # 向左
        else:
            self.state = min(5, self.state + 1)  # 向右

        reward = self.rewards[self.state] # 即时奖励
        terminated = self.state in (0, 5)  # 到达 0 或 5 结束
        truncated = False

        return self.state, reward, terminated, truncated, {}
q-learning每次采样得到的Q去微调Q表
def q_learning(env, episodes=1000000, alpha=0.01, gamma=0.9, epsilon=0.3):
    """
    Args:
        env：用于采样的环境
        episodes：回合数，环境重启的次数
        alpha：学习率
        gamma：折扣系数
        epsilon：epsilon-贪婪策略的那个参数
    """
    n_states = env.observation_space.n # 状态数量
    n_actions = env.action_space.n # 动作数量
    Q = np.zeros((n_states, n_actions), dtype=np.float32) # Q表

    for ep in range(episodes):
        # 开始一个新的episode
        state, _ = env.reset()
        done = False # 记录当前episode是否结束
        
        # agent在一个episode和环境交互的循环
        while not done:
            # ε-greedy 选择动作
            if np.random.random() < epsilon:
                action = env.action_space.sample()
            else:
                action = int(np.argmax(Q[state]))

            next_state, reward, terminated, truncated, _ = env.step(action) # 得到新状态、即时奖励等信息
            done = terminated or truncated

            td_target = reward + gamma * np.max(Q[next_state])*(1-terminated) # 实际采样得到的Q

            td_error = td_target - Q[state, action] 
            Q[state, action] += alpha * td_error # 根据实际采样得到的Q去微调Q表，alpha是学习率

            state = next_state

    return Q

Q-learning中td_target = reward + gamma * np.max(Q[next_state])*(1-terminated)这步我觉得乘不乘(1-terminated)都无所谓，因为边界状态对应Q表为0。但是DQN中，开始随机假设那个Q可能边界条件下对应非0值。下个状态处于边界，就不应该给未来预期收益了！

DQN方法

以gymnasium的lunar lander为例，给出其用于近似Q的DQN算法：

  1. 随机初始化网络，hint：这个网络输入输出在下各个动作对应的构成的向量，见上图。这是一种网络设计，这种多输出的网络设计的计算效率比较高（减少前馈所需次数），好理解的还是左侧输入右侧输出
  2. 重复。终止条件一般是设置最大回合数（gymnasium环境最大重启次数）或者agent达标分数，以下是强化学习一个回合要干的事儿：
    1. replay buffer回放缓冲区存储最近2000条agent和环境的交互信息，每局游戏可能只能拿到几百条信息。重复玩，直到replay buffer满了2000条（这是一个经验数，不一定非得设置这个）信息才进入2.2。如果已经存满2000条信息了，那新信息将覆盖旧信息
    2. 根据replay buffer放的最近2000条信息，利用的副本和bellman方程构造神经网络的输入输出，hint：构造数据集的时候不直接用，而是用它的副本（参数更加落后）可以有效缓解神经网络训练过程loss的振荡
    3. 设置batch_size比方说64，使用MSGD训练神经网络，更新
    4. 定期将的参数赋给

关于BGD,SGD和MSGD：区别在于每次前向船舶算值再反向传播更新参数的时候用多少数据。如果用全部数据就是批量梯度更新BGD；如果只用一条数据就是随机梯度更新SGD；如果是用部分数据就是小批量随机梯度更新。

思考强化学习和监督学习的区别与联系：区别在于数据不是事先准备好的，而是通过agent与环境的互动过程采集，当数据采集完后再适用监督学习方法得到近似的函数。近似效果可能不好？那就重复这个过程，慢慢逼近。

一些改进策略

  1. 贪婪策略：agent和环境交互的时候不总是采取贪婪策略选取动作，而是以一定的概率随机选择动作。这个策略的合理性在于DQN刚开始的时候对于Q的近似可能是很差的，所以贪婪策略本身并不一定好。
  2. 参数软更新策略：类似列生成算法的对偶平滑操作。这个策略可以帮助强化学习更可靠的收敛，缓解振荡。就是让每个回合都慢慢靠近，而不是当前的硬更新策略（定期把的参数赋给） 
用DQN近似Lunar Lander的Q表
# 相关包导入
import random
import collections
import gymnasium as gym
import numpy as np
import torch

class DNN(torch.nn.Module):
	def __init__(self,state_dimension,action_number):
		super(DNN,self).__init__()
		self.layers = torch.nn.Sequential(
			torch.nn.Linear(in_features=state_dimension, out_features=128, bias=True),torch.nn.ReLU(), # 输入->隐藏层1
			torch.nn.Linear(in_features=128, out_features=128, bias=True),torch.nn.ReLU(), # 隐藏层1->隐藏层2
			torch.nn.Linear(in_features=128, out_features=action_number, bias=True), # 隐藏层2->输出
		) 
	def forward(self,state):
		Q = self.layers(state)
		return Q

def dqn_method(environment,model,model_copy,criterion,optimizer,episodes,epsilon,epsilon_min,epsilon_decay,capacity,gamma,batch_size,rate,tau):
	replay_buffer = collections.deque(maxlen=capacity) # replay buffer存放近期的agent-环境交互记录
	for episode in range(1,episodes+1):
		current_state, _ = environment.reset() # 重启回合
		episode_done = False # 如果为True表明当前回合结束
		episode_rewards = 0 # 当前回合获得的总奖励
		# agent与环境交互循环（动作->观察->动作->观察->...），直到本回合结束
		while not episode_done:
			if random.random()<epsilon:
				# 随机选择一个动作
				action = environment.action_space.sample()
			else:
				# 根据Q表选择最好的动作
				with torch.no_grad(): # pytorch在前向传播的时候会构造计算图，这里我们不需要反向传播，所以把计算图构造临时关闭
					action = model(torch.tensor(current_state.astype(np.float32))).argmax().item() # pytorch需要张量输入，所以需要转一下数据，item将单元素张量转换为python标量
			# 环境信息反馈给agent 下一个状态、即时奖励、是否终止、回合是否截断，把需要用的信息存储到replay buffer里面
			next_state, reward, terminated, truncated, _ = environment.step(action) 
			episode_done = terminated or truncated 
			replay_buffer.append(
				(current_state, action, reward, next_state, terminated)
			)
			current_state = next_state
			if len(replay_buffer)<batch_size:
				continue
			# 从缓冲池中随机取batch_size个交互信息构造DNN的输入和输出，对DNN进行训练
			current_state_batch,action_batch,reward_batch,next_state_batch,terminated_batch = zip(*random.sample(replay_buffer,batch_size)) 
			current_state_batch = torch.tensor(current_state_batch,dtype=torch.float32) # 一维nadrray列表->张量
			action_batch = torch.tensor(action_batch,dtype=torch.long).unsqueeze(1) # int列表->张量
			reward_batch = torch.tensor(reward_batch,dtype=torch.long).unsqueeze(1) # float列表->张量
			next_state_batch = torch.tensor(next_state_batch,dtype=torch.float32) # 一维nadrray列表->张量
			terminated_batch = torch.tensor(terminated_batch,dtype=torch.float32).unsqueeze(1) # bool列表->张量
			with torch.no_grad(): # pytorch在前向传播的时候会构造计算图，这里我们不需要反向传播，所以把计算图构造临时关闭
				# 用model_copy和 bellman方程取近似得到真实标签
				target_batch = reward_batch+gamma*model_copy(next_state_batch).max(1, keepdim=True)[0]*(1-terminated_batch)# tensor的max(dim=1) 表示在维度 1（动作维度）上取最大值。返回值是一个 namedtuple （最大值，最大值对应idx），和ndarray的max方法行为不一样，所以这里有[0]
			# 用model预测的标签，注意标签和网络输出的标签不一样，因为bellman方程计算的原因，对于每个样本，标签是1维的。所以这里用gather变一下形式，但无所谓，只要我们能算一个相关的损失值就行
			pred_target_batch = model(current_state_batch).gather(1,action_batch) # 前向传播得到结果，并改变形状
			loss = criterion(pred_target_batch,target_batch) # 计算损失
			loss.backward() # 反向传播算梯度
			optimizer.step() # 参数更新
			optimizer.zero_grad() # 梯度信息清空，否则会累加
			# DNN训练完毕，软更新model_copy
			with torch.no_grad():
				for model_copy_param, model_param in zip(model_copy.parameters(), model.parameters()):
					model_copy_param.copy_(tau * model_param + (1.0 - tau) * model_copy_param)
			episode_rewards += reward
		else:
			epsilon = max(epsilon_min,epsilon_decay*epsilon) # epsilon衰减
			if episode % (episodes//20):
				print("episode[{}]->epsilon[{}],episode_rewards[{}]".format(episode,epsilon,episode_rewards))
	# 训练完毕
	model_trained = model
	return model_trained	 

if __name__ == '__main__':
	# 超参数
	episodes = 2000 # agent交互环境的重启次数（每达到边界状态，回合便终止）
	capacity = 100000 # replay buffer的容量（太小会导致反复采样同一批旧样本）
	batch_size = 64 # 每次用于训练DNN的样本量（原代码2000过大，训练极慢且梯度噪声低）
	rate = 1e-3 # 神经网络的学习率（0.95对Adam来说是灾难性大，参数会直接跑飞，这是不收敛的首要原因）
	epsilon = 1.0 # epsilon-贪婪动作选择策略的初始值，之后按epsilon_decay逐回合衰减
	epsilon_min = 0.05 # epsilon的下限
	epsilon_decay = 0.995 # 每回合的衰减系数
	gamma = 0.99 # bellman方程中的折扣系数（为了保证收敛性引入的）
	tau = 0.005 # 目标网络model_copy通过model软更新
	
	# 创建agent交互环境
	environment = gym.make("LunarLander-v3")
	state_dimension, = environment.observation_space.shape # 状态空间维数
	action_number  = environment.action_space.n # 可用动作数
	
	# 随机初始化网络模型
	model,model_copy = DNN(state_dimension,action_number),DNN(state_dimension,action_number)
	model_copy.load_state_dict(model.state_dict()) # 把model_copy的网络参数设置为model的网络参数
	criterion = torch.nn.SmoothL1Loss() # Huber损失：对离群奖励比MSE更稳健，是DQN的常用选择
	optimizer = torch.optim.Adam(model.parameters(), lr=rate) # 优化求解器

	# 运行dqn，做训练
	model_trained=dqn_method(environment,model,model_copy,criterion,optimizer,episodes,
		epsilon,epsilon_min,epsilon_decay,capacity,gamma,batch_size,rate,tau)
	torch.save(model_trained.state_dict(), "./lunar_lander.pth")
用近似的Q表指导飞行器降落
import torch
import gymnasium as gym
import imageio
from DQN import DNN

environment = gym.make("LunarLander-v3",render_mode="rgb_array")
trained_model = DNN(environment.observation_space.shape[0],environment.action_space.n)
trained_model.load_state_dict(torch.load("lunar_lander.pth", map_location="cpu"))
trained_model.eval() # 推理模式
observation, info = environment.reset()
done = False
frames = []
while not done:
    with torch.no_grad():   
        action = trained_model(torch.tensor(observation,dtype=torch.float32)).argmax().item()  
    observation, reward, terminated, truncated, info = environment.step(action)
    frame = environment.render()
    if frame is not None:
        frames.append(frame)
    done = terminated or truncated
environment.close()
imageio.mimsave("lunar_lander.gif", frames, fps=30, loop=0)
